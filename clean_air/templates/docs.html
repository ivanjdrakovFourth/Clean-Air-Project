Small API. Clear answers.

The service is unauthenticated and bound to localhost. Comparisons and table browsing are read-only; explicit local actions manage alerts, credentials and queued maintenance. Mutation endpoints reject foreign browser origins. This is a trusted local application, not an Internet-facing or multi-user security boundary. This documentation works offline.

GET /api/cleanest

Find the cleanest measured Bulgarian station or city. Omit both dates for the latest common recent reported hour. Set both dates for history; the end date is inclusive and both must be completed UTC days.

A successful response contains winners, ordered rankings, excluded_locations (also exposed as excluded_cities for compatibility), station addresses and coordinates when available, period, reference, methodology, a reproducible policy_id, attribution and warnings. Raw concentrations are not rounded before comparison. Time searches show the best 50 rows and disclose their total candidate count.

Combined responses instead contain is_combined, selected-source panels and agreement diagnostics. They do not invent one pooled winner. Diagnostic station values use a shared reported hour or exactly shared valid historical days. Ozone has no WHO 24-hour reference here; a custom daily reference is required for an O3 reference-day ranking.

Errors use {"error": {"code": "...", "message": "...", "details": ...}}. Status 422 indicates an invalid request, unavailable period or insufficient coverage; status 503 indicates pending initial collection or unavailable local storage. Source outages do not prevent searches of previously imported history.

Operations endpoints

  • GET /api/status: collection progress, available history, freshness and worker state.
  • GET /api/monitoring: source health, city coverage, actual Prometheus queries and maintenance outcomes.
  • GET /api/collection-notices: current startup session and unread per-source automatic update outcomes. The OK-only startup acknowledgement does not gate collection.
  • POST /api/settings/collection-desktop: local optional Windows delivery preference for automatic source-update outcomes, using {"enabled": true} or false.
  • GET /api/data and GET /api/data/export: source/table filters, pagination and CSV. No arbitrary SQL.
  • GET /api/alerts: saved rules and persistent events. POST /api/alerts, PUT /api/alerts/{id} and DELETE /api/alerts/{id} manage rules through the local interface.
  • GET /api/jobs and POST /api/jobs: source-specific backup, archive, restore, diagnostics and benchmark jobs. Queued is not the same as completed.
  • POST /api/sources/{source}/refresh: request an enabled collector refresh; respects offline mode and source locks.
  • POST /api/settings/openaq-key: store a Windows user-encrypted local API credential. Keys are not returned or bundled.
  • GET /health/live: application liveness.
  • GET /health/ready: 200 after the initial import, otherwise 503.
  • GET /metrics: Prometheus metrics for API and collection health.
  • GET /openapi.json: generated machine-readable API schema.

Daily-reference counts describe station or city daily means and do not establish regulatory or WHO compliance. Daily thresholds are not applied to hourly readings.
