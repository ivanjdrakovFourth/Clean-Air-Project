A successful response contains winners, ordered rankings, excluded_cities, reference, methodology, a reproducible policy_id, source attribution and warnings. Raw concentrations are not rounded before comparison.

Errors use {"error": {"code": "...", "message": "...", "details": ...}}. Status 422 indicates an invalid request, unavailable period or insufficient coverage; status 503 indicates pending initial collection or unavailable local storage. Source outages do not prevent searches of previously imported history.

Operations endpoints

  • GET /api/status: collection progress, available history, freshness and worker state.
  • GET /health/live: application liveness.
  • GET /health/ready: 200 after the initial import, otherwise 503.
  • GET /metrics: Prometheus metrics for API and collection health.
  • GET /openapi.json: generated machine-readable API schema.

Daily-reference counts describe city means and do not establish regulatory or WHO compliance. See the main page and the handover documentation for methodology and limitations.
